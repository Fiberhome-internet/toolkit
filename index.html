Cable type info

Telephone line wiring — landline

RJ11 — Single line (most common)
RJ11 — Dual line
RJ45 — Telephone over Ethernet cable (4 pairs)
Important notes:
• Line 1 (primary) — always Blue/White-Blue pair (pins 3 & 4 on RJ11)
• Line 2 (secondary) — always Black/Yellow pair (pins 2 & 5 on RJ11)
• Telephone line carries 48V DC — do not connect to network equipment
• Use RJ11 (6P2C or 6P4C) for phones, RJ45 only for structured cabling systems
• DSL/ADSL runs on the same pair as Line 1 — Blue/White-Blue

Solutions — how to improve latency

QUICK WINS
✔ Restart your router and modem — fixes 60% of latency issues
✔ Use a wired cable instead of WiFi — reduces latency by 10–50ms
✔ Connect to 5GHz WiFi instead of 2.4GHz if close to the router
✔ Close background apps and downloads while testing
✔ Check that no one else on the network is streaming or downloading
ROUTER SETTINGS
⚙ Enable QoS in router settings — prioritizes important traffic
⚙ Change DNS to 1.1.1.1 (Cloudflare) or 8.8.8.8 (Google) — faster resolution
⚙ Switch WiFi channel to a less congested one (use WiFi analyzer)
⚙ Update router firmware to latest version
⚙ Disable SIP ALG if VoIP calls have high latency
CALL ISP
📞 If average ping is above 100ms consistently — report to ISP
📞 If jitter is above 30ms — likely a line quality issue, request a line test
📞 If max ping spikes above 500ms — possible congestion or faulty equipment
📞 If packet loss is above 1% — request immediate line inspection
HARDWARE
🔧 Replace old Cat5 cables with Cat6 — especially runs over 30m
🔧 Check all RJ45 connectors and re-crimp any that look damaged
🔧 Replace router older than 4 years — hardware degrades over time
🔧 Add a WiFi extender or mesh node if client is far from router
